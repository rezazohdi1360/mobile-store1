پوشه icon — همه‌ی تصاویر ثابت سایت (لوگو، بنر، آیکون و ...) به‌صورت پوشه‌بندی‌شده
این پوشه در هر بار اجرای سایت خوانده می‌شود؛ برای تغییر کافی است فایل را بگذارید یا جایگزین کنید (نیازی به تغییر کد نیست).

  logo/          لوگوی فروشگاه
                   01.*  لوگوی اصلی (هدر، فاکتور PDF، صفحه خوش‌آمدگویی، API)
                   variants/  نسخه‌های دیگر لوگو (استفاده نمی‌شوند؛ فقط نگهداری)
  enamad/        نماد اعتماد الکترونیک (اینماد) در فوتر
                   01.*      تصویر پیش‌فرض
                   custom.*  اگر وجود داشته باشد، به‌جای 01 نمایش داده می‌شود (اختیاری)
                 آدرس مقصد از «پنل مدیریت ← تنظیمات سایت» تنظیم می‌شود
  banner/        بنر پس‌زمینه صفحه خوش‌آمدگویی
                   01.*  (اختیاری؛ اگر نباشد پس‌زمینه‌ی رنگی پیش‌فرض نمایش داده می‌شود)
  icons/         آیکون‌های کوچک: آیکون برنامه، favicon، آیکون دسته‌ها و ...
  placeholder/   تصویر جایگزین «بدون عکس» (no-image.png و no-image.jpg)
  .cache/        خودکار ساخته می‌شود (نسخه‌ی بدون حاشیه‌ی لوگو) — دست نزنید

پوشه‌ی جدید لازم دارید؟ داخل icon یک پوشه بسازید (مثلاً icon/payment/) و در کد با
  icon_list('payment')              ← آدرس همه‌ی تصاویر پوشه
  icon_group_url('payment', 'zarinpal')   ← یک تصویر با نام مشخص (بدون پسوند)
  icon_group_url('payment')         ← اولین تصویر پوشه
خوانده می‌شود. (در صفحات داخل admin پارامتر آخر را '../' بدهید.)

پسوندهای مجاز: jpg, jpeg, png, webp, gif, svg, ico (حروف بزرگ و کوچک فرقی ندارد).
